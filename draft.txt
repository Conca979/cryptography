II. What is image Scraping?
 -> the automated process of extracting and downloading image files (such as JPEGs, PNGs, or SVGs) and their associated metadata from websites using scripts, bots, or specialized software rather than saving them manually one by one.

 -> How It Works

    • Parse HTML: A script reads the source code of a target webpage to locate image tags (like <img>) or background styling attributes.
    • Resolve URLs: It converts relative paths into full, direct image web addresses (URLs).
    • Fetch and Save: The tool sends HTTP requests to download the actual image binaries and stores them in local folders or cloud databases.
    • Handle Dynamic Content: Advanced scrapers use headless browsers (like Selenium or Puppeteer) to simulate scrolling and load JavaScript-heavy galleries.
