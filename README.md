## Project Structure and File Index

The following index lists all tracked and active files in this repository (excluding files and directories defined in `.gitignore`).

### Root Files

- `.gitignore`: Git configuration specifying intentionally untracked paths (caches, virtual environments, local playgrounds, temporary test artifacts).
- `.python-version`: Version declaration fixing the Python runtime environment to Python 3.10.
- `pyproject.toml`: Project build configuration and package dependency metadata.
- `report.tex`: Academic course project report authored in LaTeX, detailing the mathematical foundations, system architecture, and experimental benchmarks.
- `uv.lock`: Deterministic dependency lockfile generated by the `uv` package manager.
- `README.md`: This file; repository overview, file index, and usage instructions.

### Viewing the Presentation Slides
Open `docs/slides/slides.html` directly in any modern web browser:
- Press `Right Arrow` or `Space` to advance slides.
- Press `Left Arrow` to navigate backward.
- Press `N` to toggle the presenter notes drawer containing spoken talking points.

### Core Source Code (`src/cryptography/`)

Server-side Python transposition routines and client-side JavaScript canvas decoders.

- `src/cryptography/__init__.py`: Python package initialization marker for the cryptography module.
- `src/cryptography/grt_server.py`: Server-side implementation of the Generalized Rectangular Transform (GRT). Contains strict 4-condition parameter validation, forward affine coordinate mapping with dynamic translation offset $(r_m, r_n)$ to eliminate origin fixed points, and bit-exact image tile permutation.
- `src/cryptography/igrt_client.js`: Client-side Inverse Generalized Rectangular Transform (IGRT) HTML5 Canvas decoder. Implements positive Euclidean modulo arithmetic, Extended Euclidean modular inversion, and the 4-stage exact coordinate uncoupling pipeline (Equilateral, Projection, Triangular Cases 1-3, and CRT reconstruction).

### Documentation and References (`docs/`)

Technical reports, research notes, slide presentations, and academic paper references.

#### Core Technical Reports & Notes
- `docs/benchmark_report.md`: Experimental benchmark report measuring computational execution latency ($T_{\text{enc}}$, $T_{\text{dec}}$), heap memory footprint via `tracemalloc`, and compression overhead across PNG, WebP, and JPEG formats, complete with ready-to-copy LaTeX `booktabs` tables.
- `docs/references.md`: Primary and secondary bibliographic citations including Lan & Wang (2025) and Hariyanto & Rahim (2016).
- `docs/srt_and_grt_handwritten_notes.md`: Detailed mathematical documentation deconstructing handwritten derivations for SRT and GRT. Explains parameter definitions ($M, N, p, h, v, r, s$), Condition 5 wrap elimination proofs, diagonal coprimality, and the stationary origin flaw.

#### Presentation Deck (`docs/slides/`)
- `docs/slides/slides.html`: Standalone modern white slide presentation deck (12 slides) designed for project defense. Includes full keyboard navigation, progress bar, typeset mathematical matrices, and collapsible presenter notes.
- `docs/slides/slides.css`: Styling rules for the modern white slide deck, providing clean typography, responsive layout, and custom CSS-typeset matrix brackets.

#### Academic Reference Papers (`docs/papers/`)
- `docs/papers/A_Novel_Multi-Image_Encryption_Scheme_Using_Generalized_Rectangular_Transform_and_Advanced_5-D_Hyperchaotic_Map.pdf`: Foundational research paper by Lan and Wang (IEEE Access 2025) introducing SRT and GRT.
- `docs/papers/A_symmetric_image_encryption_scheme_base.pdf`: Reference literature on 3D chaotic cat maps for symmetric image encryption.
- `docs/papers/arnolds_cat_map.pdf`: Reference paper on Arnold's Cat Map in digital image encryption by Hariyanto and Rahim (2016).

#### Handwritten Mathematical Derivations (`docs/GRT/` and `docs/SRT/`)
- `docs/GRT/1.jpg` to `docs/GRT/12.jpg`: Photographic scans of handwritten mathematical proofs for Generalized Rectangular Transform (setup, 4 conditions, equilateral inversion, projection mapping, triangular uncoupling Cases 1-3, and Chinese Remainder Theorem reconstruction).
- `docs/SRT/1.jpg` and `docs/SRT/2.jpg`: Photographic scans of handwritten mathematical proofs for Special Rectangular Transform (formulation, Condition 5 wrap decoupling, ISRT derivation, and area preservation).

#### Image Assets (`docs/images/`)
- `docs/images/t1.png`: Photographic test image asset 1 used for benchmarking and validation.
- `docs/images/t2.png`: Photographic test image asset 2 used for benchmarking and validation.
- `docs/images/t3.png`: Photographic test image asset 3 used for benchmarking and validation.
- `docs/images/t4.png`: Photographic test image asset 4 ($612 \times 408$ pixels) used as the standard benchmark image across $18 \times 12$ and $6 \times 4$ tile grids.

### Prerequisites
- Python 3.10 or newer
- `uv` package manager (or standard `pip`)
- Modern web browser (Chrome, Firefox, Safari, Edge) for viewing slides and HTML5 canvas decoding

### Running the Python Environment
Install dependencies and run scripts using `uv`:

```bash
# Sync dependencies via uv
uv sync

# Run Python scripts within the project virtual environment
uv run python src/cryptography/grt_server.py
```
